🧪 خطة الاختبار الشاملة قبل الإطلاق
Unit Tests

جميع tRPC procedures (input validation, business logic)
sdk.ts — verifySession, createSessionToken
db.ts — upsertUser, getUserByOpenId
env.ts — parseInteger, parseBoolean, assertProductionEnvironment

Integration Tests

OAuth callback flow كامل
Session creation وverification
Rate limiting behavior
Database migrations

Security Tests

OWASP Top 10 scan
SQL injection على جميع الـ inputs
XSS في حقول المستخدم
CSRF على الـ mutations
JWT tampering
Rate limit bypass attempts

Performance Tests

Load testing بـ k6 أو Artillery (100 concurrent users)
Database query performance (EXPLAIN ANALYZE)
Bundle size analysis (< 500KB initial)
Lighthouse score (> 90 لكل metric)

E2E Tests (Playwright)

تسجيل الدخول الكامل
إكمال وحدة تعليمية
إجراء اختبار MCQ
عرض الشهادة
