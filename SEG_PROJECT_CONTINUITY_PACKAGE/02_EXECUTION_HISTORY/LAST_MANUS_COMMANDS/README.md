# LAST_MANUS_COMMANDS

هذا المجلد يحفظ سجل الأوامر التنفيذي الأخير. السجل الأساسي هو `COMMAND_LEDGER.md`، أما الأوامر التفصيلية المعتمدة فتوجد في المستوى الأب:

- `SEG_FINAL_UI_CONSISTENCY_AUDIT_COMMAND.md`
- `SEG_DASHBOARD_UX_FINAL_REVIEW_COMMAND.md`
- `SEG_VISUAL_ASSET_REGISTRY_COMMAND.md`
- `NEXT_PENDING_COMMANDS.md`

لا تُعاد أوامر المراجعة أو التنفيذ تلقائياً؛ يجب قراءة `LAST_MANUS_STATE.md` و`SEG_CHANGE_CONTROL_RULES.md` قبل تشغيل أي أمر جديد.
