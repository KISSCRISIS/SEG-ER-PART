# Jordan Emergency Medicine Nexus (JEM Nexus)

## Project Lineage

This documentation package describes the JEM Nexus context while preserving the Smart Emergency Guide (SEG) project as its documented governance lineage. This lineage statement is historical and contextual; it does **not** assert an officially completed SEG-to-JEM Nexus rename, a repository merge, an architecture replacement, a transfer of ownership, or authorization to integrate the two systems.

For current SEG governance purposes, JEM Nexus remains a separately governed calculator/tool path unless a future, explicit project-level decision states otherwise. The official SEG governance records remain authoritative for SEG source-registry decisions, evidence states, normalization approval, and implementation boundaries.

# Project Overview

Jordan Emergency Medicine Nexus (JEM Nexus) is documented here as a governed emergency medicine knowledge-platform context intended to organize, validate, and deliver structured educational resources for emergency medicine learners and healthcare professionals.

The documentation emphasizes evidence-aware clinical knowledge management through controlled source verification, medical review workflows, provenance tracking, and structured content governance. The documentation itself does not constitute clinical content approval or authorization to integrate a medical tool into SEG.

## Normalization Boundary

```text
NORMALIZATION: BLOCKED_PENDING_APPROVED_SOURCE
NORMALIZATION_AUTHORIZATION: NOT_CURRENTLY_AUTHORIZED
```

Normalization is a **conditional future phase**. It is not currently authorized. Entry requires at least one source to achieve `READY_FOR_NORMALIZATION` through source-specific evidence closure and explicit governance approval.

No clinical content is considered production-ready until it completes, at minimum:

1. Source identity verification.
2. Provenance validation.
3. Rights assessment.
4. Required medical review and approval.
5. Version control.
6. Audit-trail registration.
7. The applicable professional-track and technical, visual, or accessibility reviews.

Until those conditions are satisfied, the permitted state remains controlled documentation, source preservation, and evidence review only. No normalization, content import, database integration, activation, publication, or learner exposure is authorized by this document.
