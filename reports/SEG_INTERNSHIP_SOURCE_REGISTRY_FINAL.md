## 3. Registry field interpretation

`Pathway` is a provisional handoff label because the source paths are under `02_Internship`; it is not a final professional-track approval. `Content type` is a source-role candidate classification. In particular, TSX/TypeScript files, parsers, question-data modules, manifests, page files, and README files are not promoted to learner-facing content by this registry.[1] [2]

`Version status` is `NOT_SUPPLIED` unless the filename contains a literal `v2` token; in that case the status is `NOT_GOVERNED — filename v2 signal only`. A filename signal is not a version decision. `Rights status` remains `NOT_SUPPLIED` for every row. `Review status` preserves the catalog value and does not mean clinical approval. `Governance status` records the pending handoff needed before schema conversion.
